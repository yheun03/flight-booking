AppToast (useToast)

Figma 토스트 팝업입니다. useToast() 로 호출합니다.

  • show(message | options) : 기본 토스트
  • success / error / warning / info : tone 이 지정된 토스트
  • remove(id) / clear() : 닫기
const toast = useToast();
                    toast.show('즐겨찾기로 표시되었습니다.');
  • success : 완료
  • danger : 오류 (toast.error)
  • warning : 경고
  • info : 안내
  • meta : string
  • duration : ms (기본값 2500), 0 이면 자동으로 닫히지 않음
  • closable : 닫기 버튼 노출
  • actionText : 버튼 문구
  • onAction : 클릭 시 실행 함수
  • bottom : 하단 중앙 (기본값)
  • top : 상단 중앙
  • bottom-right / top-right : 우측 하단 / 우측 상단
<AppToastHost placement="bottom-right" />
