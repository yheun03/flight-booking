디자인 토큰

Figma 타이포그래피(PC/MO)와 컬러 테이블을 SCSS 토큰으로 정리한 값입니다. 화면에 표시되는 값은 실제 적용된 CSS 변수입니다.

  • SCSS : @include font(b3, rg) / font(t1, sb, en)
  • Class : typo-b3 + typo-lt | typo-rg | typo-sb + typo-en
  • 자간 : 국문 -2.5% (kr, 기본) / 영문 0 (en)
  • 굵기 : lt 300 / rg 400 / sb 600

현재 적용: PC 스케일 (뷰포트 0px)
